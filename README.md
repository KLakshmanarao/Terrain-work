It consists of seven labels such as Desert, Forest, Grassy, Marshy, Mountain, and Plains. Furthermore, the dataset divided into
test, train, and validation data. The complete information of dataset is described in Table 1.

### Table 1: Dataset with class wise count

| Split | Desert | Forest | Grassy | Marshy | Mountain | Plains |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **Train** | 10305 | 2641 | 8512 | 7727 | 10309 | 639 |
| **Test** | 1920 | 276 | 1824 | 1657 | 1920 | 81 |
| **Validation** | 1916 | 274 | 1824 | 1656 | 1917 | 79 |
| **Total** | 14141 | 3191 | 12160 | 11040 | 14146 | 799 |
